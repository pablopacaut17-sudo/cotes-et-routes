Aérodrome de Nemba

L’aérodrome de Nemba est un aérodrome situé à Nemba, dans le district de Bugesera, dans la province de l'Est, au Rwanda.

Situation

L'aérodrome se trouve dans le sud-est du Rwanda, à proximité de la frontière avec le Burundi. Il dessert la localité de Nemba, dans le district de Bugesera.

Il est localisé autour des coordonnées 2° 19′ 48″ S, 30° 12′ 00″ E et se situe à une altitude d'environ 1 495 m, soit 4 905 ft, au-dessus du niveau de la mer.

Caractéristiques

L'aérodrome possède le code OACI HRYN. Aucun code AITA n'est indiqué dans les sources consultées.

Les données aéronautiques disponibles indiquent une piste orientée 13/31, longue d'environ 1 100 m, soit 3 600 ft, avec un revêtement en latérite. Une autre base aéronautique confirme l'existence d'une piste 13/31 à Nemba.
