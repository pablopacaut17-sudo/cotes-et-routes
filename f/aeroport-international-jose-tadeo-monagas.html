Aéroport international José Tadeo Monagas

L’aéroport international José Tadeo Monagas (espagnol : aeropuerto Internacional José Tadeo Monagas, code IATA : MUN • code OACI : SVMT), est un aéroport desservant Maturín, capitale de l'Etat de Monagas au centre du Venezuela.
