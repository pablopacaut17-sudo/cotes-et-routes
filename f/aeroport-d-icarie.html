Aéroport d'Icarie

L’aéroport national d’Icarie (en grec moderne : Κρατικός Αερολιμένας Ικαρίας, code IATA : JIK • code OACI : LGIK) est un aéroport situé sur l’île d’Ikaria/Icarie, en Grèce.

L’aéroport a ouvert le 14 juin 1995 avec deux vols hebdomadaires d’Olympic Airlines sur DO 228. . Les bâtiments se situent dans une zone de 1 000 mètres carrés.
