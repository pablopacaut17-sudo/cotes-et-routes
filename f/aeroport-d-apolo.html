Aéroport d'Apolo

L'aéroport d'Apolo (code IATA : APB • code OACI : SLAP), est un aéroport de Bolivie. Sa piste d'atterrissage dessert la ville d'Apolo, dans le département de La Paz.

Apolo se trouve dans une vallée étendue de la cordillère Royale. Il y'a un terrain montagneux dans tous les quadrants, sauf au nord-nord-ouest. La balise non directionnelle Apolo (identifiant : APB ) est localisée sur le terrain.
