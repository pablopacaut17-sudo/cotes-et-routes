Aéroport Alberto Delgado

Aéroport Alberto Delgado ( Espagnol : Aeropuerto Alberto Delgado ) (code IATA : TND • code OACI : MUTD) est un aéroport desservant Trinidad, une ville de la province de Sancti Spíritus, à Cuba.
