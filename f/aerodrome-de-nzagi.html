Aérodrome de Nzagi

L'aéroport de Nzagi (code IATA : NZA • code OACI : FNZG) est un aéroport desservant Nzagi, aussi appelée Andrada, dans la province de Lunda-Nord, dans le nord-est de l'Angola.

Caractéristiques

L'aéroport est identifié par le code AITA NZA et le code OACI FNZG. Il se trouve aux coordonnées 7° 43′ sud et 21° 21′ est, à une altitude d'environ 741 mètres au-dessus du niveau de la mer.

L'installation est un aérodrome civil situé à environ 3 km au sud de Nzagi. Sa piste est orientée 08/26.
