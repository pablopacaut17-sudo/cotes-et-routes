Aéroport international de Belém

L'aéroport international de Belém – Val-de-Cans/Júlio-Cezar-Ribeiro (code IATA : BEL • code OACI : SBBE • Code aérodrome du Brésil : PA0001) est le principal aéroport desservant Belém, au Brésil. Val de Cans (parfois orthographié Val de Cães) est le nom du quartier où se situe l'aéroport. Depuis le 13 avril 2010, l'aéroport est nommé aussi en l'honneur de Júlio Cesar Ribeiro de Souza (1837-1887) un inventeur, concepteur de ballons dirigeables.
