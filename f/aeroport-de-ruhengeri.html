Aéroport de Ruhengeri

L’aéroport de Ruhengeri (code IATA : RHG • code OACI : HRYU) est un aéroport situé à Ruhengeri, dans le district de Musanze, dans la province du Nord, au Rwanda.

Situation

L'aéroport dessert la ville de Ruhengeri, également appelée Musanze, dans le nord du Rwanda. Il est localisé autour des coordonnées 1° 29′ 49″ S, 29° 37′ 53″ E et se situe à une altitude d'environ 1 860 m, soit 6 102 ft, au-dessus du niveau de la mer.

Caractéristiques

L'aéroport possède le code AITA RHG et le code OACI HRYU. Il est classé comme petit aéroport dans les bases de données aéronautiques internationales.

Les données aéronautiques disponibles indiquent une piste principale d'environ 1 480 m, soit 4 860 ft. Selon les bases consultées, l'orientation de la piste est indiquée comme 15/33 ou 14/32, ce qui peut correspondre à des différences de mise à jour ou d'arrondissement des données aéronautiques.
