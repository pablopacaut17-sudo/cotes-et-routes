Aéroport d'Ambriz

L'aéroport d'Ambriz (code IATA : AZZ • code OACI : FNAM) est un aéroport privé desservant Ambriz, dans la province de Bengo, en Angola.

Situation

L'aéroport est situé à proximité de la ville d'Ambriz, sur le littoral nord de l'Angola. Il est établi à une altitude d'environ 44 m.

Installations

L'aéroport est référencé par le code IATA AZZ et le code OACI FNAM.

La balise non directionnelle d'Ambriz se trouve au nord de l'aérodrome.
