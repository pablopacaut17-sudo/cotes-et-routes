Aéroport d'Arly

L'aéroport d'Arly (code IATA : ARL • code OACI : DFER), est un aéroport public situé proche du parc national d'Arli, dans la province de Tapoa, au Burkina Faso. Il est tracé d'une piste visible. L'aérodrome figure néanmoins toujours dans la publication officielle d'information aéronautique de l'ASECNA pour le Burkina Faso et possède un code IATA à trois lettres, même si son code à quatre lettres ne semble pas être reconnu par l'OACI.
