Aérodrome de Deadhorse/Prudhoe Bay

L'aéroport de Deadhorse / Prudhoe Bay code IATA : SCC • code OACI : PASC • code FAA : SCC, est un aéroport public situé à Deadhorse dans le nord de l'Alaska. Il est accessible depuis Fairbanks via les autoroutes Elliott et Dalton. Il est près de la baie de Prudhoe et est parfois aussi appelé aéroport de Prudhoe .
