Aéroport de Parme

L’aéroport de Parme (en italien, Aeroporto di Parma (code IATA : PMF • code OACI : LIMP), aussi connu sous le nom d'aéroport Giuseppe-Verdi est un aéroport italien desservant la ville de Parme. L'aéroport, géré par la Società Gestione Aeroporto Parma S.p.A, a été inauguré le 5 mai 1991.
