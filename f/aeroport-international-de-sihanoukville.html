Aéroport international de Sihanoukville

L'aéroport international de Sihanouk (anciennement aéroport de Sihanoukville) (code IATA : KOS • code OACI : VDSV)(khmer : អាកាសយានដ្ឋានអន្តរជាតិក្រុងព្រះសីហនុ Anglais : Sihanouk International Airport), est situé 20 km à l'est de Sihanoukville ville, dans la province de Preah Sihanouk, est le troisième aéroport international du Cambodge. L'aéroport est également connu comme aéroport de Kaong Kang (Kaong Kang, កោងកាង = mangrove). Le code AITA de KOS est dérivé de Kompong Som qui est l'autre nom de Sihanoukville.
