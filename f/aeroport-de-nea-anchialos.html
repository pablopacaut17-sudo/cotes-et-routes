Aéroport de Néa Anchíalos

L’aéroport national de Néa Anchíalos (grec moderne : Κρατικός Αερολιμένας Νέας Αγχιάλου / Kratikós Aeroliménas Néas Anchiálou, code IATA : VOL • code OACI : LGBL), est un aéroport situé à Néa Anchíalos, en Grèce.

Desservant la ville de Vólos, il est aussi appelé aéroport de Grèce-Centrale de Vólos–Néa Anchíalos.
