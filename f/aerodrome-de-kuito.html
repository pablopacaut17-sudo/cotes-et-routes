Aérodrome de Kuito

L'aérodrome de Kuito (portugais : Aeroporto de Kuito) (code IATA : SVP • code OACI : FNKU) est un aéroport desservant Kuito (connu sous le nom de Silva Porto avant 1975), une ville dans la province de Bié, en Angola.
