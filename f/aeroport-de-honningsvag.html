Aéroport de Honningsvåg

L’aéroport de Honningsvåg, code IATA : HVG • code OACI : ENHV, est un aéroport situé dans la commune de Nordkapp, à proximité du village de Honningsvåg, dans le comté de Finnmark, en Norvège. Il a accueilli 24 898 passagers en 2011.
