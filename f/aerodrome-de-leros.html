Aérodrome de Leros

L'aéroport municipal de Leros (en grec moderne : Δημοτικός Αερολιμένας Λέρου, Dimotikós Aeroliménas Lérou, code IATA : LRS • code OACI : LGLE • Code aéroport grec : grec moderne : ΔΑΛΕ), est un aéroport desservant l'île de Leros en Grèce. Il est également connu comme l'aéroport public de Leros ou l'aéroport de Leros. L'aéroport a commencé ses opérations en 1984.
