Aéroport d'El Paso

L'aéroport international El Paso (code IATA : ELP • code OACI : KELP • code FAA : ELP) est un aéroport public à 6 km au nord-est du centre-ville d'El Paso, dans le comté d'El Paso, Texas, États-Unis. C'est le plus grand aéroport commercial dans l'Ouest du Texas, avec 2 778 248 passagers en 2014.
