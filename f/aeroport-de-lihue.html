Aéroport de Lihue

L'aéroport de Lihue (code IATA : LIH • code OACI : PHLI • code FAA : LIH) est un aéroport public appartenant à l'État situé dans la Census-designated place de Lihue sur la côte sud - est de l'île de Kauai dans le comté de Kauai, Hawaï, États-Unis, à deux milles nautiques à l'est du centre du CDP.
