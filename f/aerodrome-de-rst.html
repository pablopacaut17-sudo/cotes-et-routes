Aérodrome de Røst

L'aérodrome de Røst ( norvégien : Røst lufthavn ; code IATA : RET • code OACI : ENRS ) est un aéroport régional desservant la municipalité de Røst dans le comté du Nordland, en Norvège. L'aéroport est situé sur le bord nord de l'île principale de Røstlandet, juste au nord du village principal de Røstlandet . Il est exploité par la société d'État Avinor et a accueilli 9889 passagers en 2014.
