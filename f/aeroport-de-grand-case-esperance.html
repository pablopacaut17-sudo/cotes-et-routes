Aéroport de Grand-Case Espérance

L'aéroport de Grand-Case Espérance (code IATA : SFG • code OACI : TFFG) est situé à Grand-Case, dans la partie française de l'île franco-néerlandaise de Saint-Martin aux Antilles. Il est utilisé par les avions de taille moyenne, les plus gros avions atterrissant sur l'aéroport international Princess Juliana dans la partie néerlandaise de l'île.
