Aéroport de Cuito Cuanavale

L'aéroport de Cuito Cuanavale (code IATA : CTI • code OACI : FNCV) est un aéroport public desservant Cuito Cuanavale, dans la province de Cuando-Cubango, en Angola.

Situation

L'aéroport est situé à proximité de la ville de Cuito Cuanavale, dans le sud-est de l'Angola. Il est référencé aux coordonnées 15° 09′ 37″ S, 19° 09′ 22″ E.

Installations

L'aéroport est identifié par le code IATA CTI et le code OACI FNCV.

Il dispose d'une piste asphaltée orientée 12/30, d'une longueur d'environ 2 735 m.

La balise non directionnelle de Cuito Cuanavale, identifiée par le code CV, est située sur le terrain de l'aéroport.
