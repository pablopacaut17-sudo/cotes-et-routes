Aéroport de Cazombo

L'aéroport de Cazombo (code IATA : CAV • code OACI : FNCZ) est un aéroport public desservant la ville de Cazombo, dans la province de Moxico Leste, en Angola.

Situation

L'aéroport est situé à proximité de Cazombo, dans l'est de l'Angola.

Installations

L'aéroport est référencé par le code IATA CAV et le code OACI FNCZ.

La balise non directionnelle de Cazombo, identifiée par le code CZ, est située sur le terrain de l'aéroport.
