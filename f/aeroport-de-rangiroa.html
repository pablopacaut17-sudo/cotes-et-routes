Aéroport de Rangiroa

L’aéroport de Rangiroa, code IATA : RGI • code OACI : NTTG, est un aérodrome situé sur l'atoll de Rangiroa dans l'archipel des Tuamotu en Polynésie française.

Le premier avion à avoir amerri sur Rangiroa est un hydravion Cams 55.
