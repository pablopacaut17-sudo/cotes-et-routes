Aéroport de Porbandar

L’Aéroport de Porbandar (code IATA : PBD • code OACI : VAPR) est un aéroport situé à Porbandar, dans l'État de Gujarat, en Inde. Un nouveau terminal a été construit durant le printemps 2008.

Compagnie aériennes et destinations

Usage militaire

La base est utilisée par l'INS Sardar Patel qui commande :

l'INS 343 du Commandement naval ouest, qui utilise des drones comme les Drishti 10,

l'INS 314 de surveillance sur Dornier 228.

La base est aussi utilisée par les Gardes-côtes indiens.
