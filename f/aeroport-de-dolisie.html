Aéroport de Dolisie

L'aéroport Ngot-Nzoungou de Dolisie (code IATA : DIS • code OACI : FCPD) est un aéroport desservant la ville de Dolisie, dans le département du Niari, en république du Congo.

La ville de Dolisie a porté le nom de Loubomo jusqu'en 1991. Le radiophare non directionnel de Dolisie, identifié par le code LO, est situé sur le terrain de l'aéroport.
