Aéroport de Salzbourg-W.-A.-Mozart

L'aéroport de Salzbourg (en allemand : Flughafen Salzburg), code IATA : SZG • code OACI : LOWS est l'aéroport de la ville de Salzbourg ; il est également connu sous l'appellation complète « Aéroport de Salzbourg-W.-A.-Mozart » (en anglais : Salzburg Airport W. A. Mozart), le célèbre musicien étant né dans la ville en 1756.
